# Artisan Connect

A simple AI-powered marketplace that connects Indian artisans with buyers.

## What it does
- Artisans upload a product photo
- AI suggests title, craft, description and price
- Buyers browse products and get recommendations
- Supports multiple Indian languages
- Includes a demo checkout flow

## Tech
- React
- Vite
- JavaScript
- Vercel serverless APIs
- Gemini API

## Run locally
```bash
npm install
npm run dev
```

## Demo note
This is a hackathon prototype. Login, orders and marketplace data are demo/local data.
